# 🌦️ Modern Weather App

A fully responsive and feature-rich **Weather Web Application** that provides real-time weather data, air quality insights, interactive maps, and data visualization using modern web technologies.

🔗 **Live Demo:** https://priyesh-weather-app.vercel.app/

---

## 🚀 Features

- 🌍 Search weather by city name
- 📍 Auto-detect current location (Geolocation API)
- 🌡️ Temperature toggle (°C / °F)
- 📊 Temperature trend graph (Chart.js)
- 🗺️ Interactive location map (Leaflet.js)
- 🌫️ Air Quality Index (AQI) with visual indicators
- 🌅 Sunrise & Sunset timings
- 💨 Wind speed & humidity details
- 📅 5-Day weather forecast
- 🎨 Modern UI with glassmorphism design
- ⚡ Fast & responsive (deployed on Vercel)

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (ES6+)**
- **OpenWeather API**
- **Chart.js** (for graphs)
- **Leaflet.js** (for maps)
- **Vercel** (Deployment)

## ⚙️ How It Works

1. User enters a city or allows location access
2. App fetches data from OpenWeather API
3. Displays:
   - Current weather conditions
   - Temperature & feels-like value
   - AQI (converted to real-world scale)
   - Forecast data
4. Visualizes:
   - Temperature trend graph
   - Map with location marker
